Jump Desktop으로 아이폰에서 맥 원격 접속 시 키보드 입력 오류와 해결법

아이폰에 블루투스 키보드를 연결해 Jump Desktop으로 맥북을 원격 제어할 때 로그인 암호가 입력되지 않거나 cmd 키가 눌린 상태로 인식되는 문제는 주로 한영 전환 상태 불일치 때문이며, 영문 입력 상태로 맞추는 것이 핵심 해결책으로 제시됐다.

#Jump Desktop #원격 데스크톱 #맥OS #한영 전환 #키보드 오류

  1. 아이폰 16 Pro Max에 모니터와 로지텍 마우스·키보드를 연결해 Jump Desktop으로 맥북 프로 M4 Pro를 원격 제어하던 중 로그인 화면에서 키보드로 암호 입력이 되지 않는 문제가 발생했다.
  2. 접속 후 키보드를 다시 페어링하면 cmd 키가 눌린 상태로 인식되어 q는 창 닫기, m은 최소화 같은 단축키로 동작했다.
  3. 한 댓글은 원인을 한영 전환 문제로 보고, Karabiner 등 서드파티 한영 전환 앱이 원격 접속 시 적용되지 않게 하고 Jump Desktop을 반드시 영문 상태로 시작하라고 조언했다.
  4. 맥 로그인 화면 메뉴바에 입력 소스를 표시해 영문으로 설정되어 있는지 확인하고, 사용 중에는 한영 전환키를 확실히 누른 뒤 다음 키를 천천히 입력하는 습관이 권장됐다.
  5. 맥 화면 오른쪽 위 입력 소스를 [한]에서 [A]로 바꾸면 해결된다는 경험담도 공유됐다.
  6. 맥 두 대끼리 연결할 때 같은 증상이 있었는데 양쪽 모두 구름 입력기를 설치하니 해결됐다는 사례가 있었다.
  7. Tailscale로 맥 두 대를 연결하고 Codex로 만든 한영 전환 동기화 앱을 사용해 문제를 해결했다는 사용자도 있었다.
