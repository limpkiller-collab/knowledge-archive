클로드 코드 /watch 스킬로 유튜브 강의를 학습시켜 스킬 만들기

깃허브 무료 스킬 /watch를 클로드 코드에 설치하면 유튜브 영상 주소만으로 클로드가 화면과 음성을 분석해 내용을 학습하고, 이를 새로운 스킬로 만들 수 있다.

#클로드 코드 #AI 스킬 #유튜브 학습 #생산성 #브랜딩

  1. /watch는 깃허브에서 별 2만 개 이상을 받은 클로드 코드용 무료 스킬이다.
  2. 영상 주소를 주면 클로드가 화면은 이미지로, 말은 텍스트로 추출해 직접 영상을 본다.
  3. 자막에 없는 화면 속 내용까지 읽어 낼 수 있다.
  4. 에디터가 브랜딩 강의 3편(조회수 합 236만)을 넣고 '보고 배워서 스킬로 만들어 줘'라고 하자 클로드에 브랜딩 스킬이 생겼다.
  5. 생성된 브랜딩 스킬은 소개글을 강의 내용대로 한 문장, 사연, 증거 순서로 고쳐 준다.
  6. 설치는 명령어 두 줄이면 되며, 클로드 데스크톱 앱의 Code 화면에서도 설치할 수 있다.
  7. 클로드 코드는 Pro 이상 유료 요금제에 포함되어 있다.
