어원 (찾아내다)
그리스어 heuriskein("찾아내다") — 아르키메데스가 욕조에서 부력을 발견하고 외친 "유레카(εὕρηκα)!"와 같은 어근. 완벽한 정답이 아닌 충분히 좋은 답을 빠르게 찾는다는 핵심은 수학의 휴리스틱이나 인지심리학의 휴리스틱이나 동일하다. — Kahneman, D. & Tversky, A. (1974). Judgment under Uncertainty: Heuristics and Biases. Science.

4대 휴리스틱 요약
휴리스틱 설명 대표 편향 / 사례
대표성
Representativeness		 전형적 사례와 닮은 정도로 확률 판단 기저율 무시, 도박사의 오류, 결합 오류(린다 실험)
가용성
Availability		 쉽게 떠오르는 것을 더 빈번하다고 판단 비행기 vs 자동차 위험 과대평가, SNS 세계 왜곡
정박·조정
Anchoring		 처음 접한 숫자/정보에 과도하게 의존 협상 첫 제시가 결과를 끌어당김, 연봉 협상
감정
Affect		 감정(호·불호)이 위험/이익 판단을 대체 좋아하는 종목의 위험을 낮게 평가
System 1 vs System 2 — 핵심 비교
⚡ System 1 — 빠른 사고
  • •자동적·무의식적 처리
  • •에너지 소비 최소화
  • •감정·직관·패턴 기반
  • •휴리스틱의 산물
  • •대부분의 일상 결정
🔬 System 2 — 느린 사고
  • •의도적·의식적 처리
  • •높은 에너지·집중 필요
  • •논리·규칙·계산 기반
  • •System 1 오류 교정 역할
  • •게으름 — 교정을 자주 포기
💡 핵심: 우리는 스스로 System 2로 생각한다고 믿지만, 실제 대부분의 결정은 System 1이 내리고 System 2가 사후 합리화한다.
