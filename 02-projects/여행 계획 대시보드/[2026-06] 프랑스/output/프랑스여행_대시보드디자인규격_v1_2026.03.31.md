# 여행 대시보드 디자인 규격서 (Design Specification)

> **기준 파일**: 프랑스여행_여행일정대시보드_v3.9_2026.03.31.html
> **작성일**: 2026-03-31
> **목적**: 향후 새 여행 대시보드 생성 시 동일한 디자인/구조를 재현하기 위한 템플릿 규격

---

## 1. 기술 스택

| 항목 | 내용 |
|------|------|
| 파일 형식 | 단일 HTML 파일 (CSS + JS 인라인) |
| 외부 CDN | Google Fonts (Inter, Noto Sans KR), html-to-image 1.11.11 |
| 로컬 저장 | localStorage (`{trip}_v{version}` 키) |
| 반응형 | 모바일 우선 (breakpoint: 768px, 600px, 375px) |
| 기본 테마 | 다크 모드 (`theme-dark`), 라이트 토글 지원 |

## 2. 폰트 시스템

### 2.1 폰트 패밀리

| 우선순위 | 폰트명 | 용도 |
|----------|--------|------|
| 1 | **Noto Sans KR** | 한국어 UI 전체 (본문, 버튼, 라벨) |
| 2 | **Inter** | 영문, 숫자 보조 |
| 3 | -apple-system, BlinkMacSystemFont | 시스템 폴백 |

- Google Fonts 웨이트: `300, 400, 500, 600, 700, 800, 900`
- 글로벌 적용: `font-family: 'Noto Sans KR', 'Inter', -apple-system, BlinkMacSystemFont, sans-serif`

### 2.2 폰트 크기 체계

| 토큰 | 크기 | 굵기 | 용도 |
|------|------|------|------|
| **hero-title** | 48px (모바일: clamp(24px, 5vw, 32px)) | 800 | 대시보드 제목 |
| **section-title** | 24px | 700 | 예산/정보 섹션 제목 |
| **panel-title** | 22px | 700 | 패널 제목 (관광스팟 등), day-meta h2, hotel-name |
| **region-section** | 18px | 700 | 지역 섹션 제목 (맛집/카페) |
| **card-title** | 16px | 600 | 타임라인 카드, 리스트 카드 h3 |
| **card-body** | 14px | 400 | 일정 desc, day-meta p, info-card p |
| **tab-label** | 14px | 600 | 메인 탭 라벨 |
| **kpi-value** | 24px (모바일: 18px) | 700 | KPI 숫자 |
| **button** | 13~15px | 500~700 | 각종 버튼 |
| **label** | 12~13px | 500~600 | kpi-label, form-label, sub-info |
| **badge** | 11px | 700 | badge-type, tag 라벨 |
| **caption** | 11~12px | 400~500 | kpi-sub, tab-date, 부가 정보 |

### 2.3 서체 속성

| 속성 | 값 | 적용 범위 |
|------|-----|---------|
| line-height | 1.6 | 글로벌 기본 |
| line-height | 1.7 | tl-desc, list-desc |

| letter-spacing | -0.02em | kpi-value, 카드 타이틀 |

### 5.2 KPI 카드 그리드

```
구조: div.kpi-grid
├── div.kpi-card (여행 기간)
│   ├── span.kpi-icon       SVG 아이콘 (stroke: var(--day1))
│   ├── span.kpi-label      "여행 기간"
│   ├── span.kpi-value      "11박 12일"
│   └── span.kpi-sub        "6/2(화)~6/13(토)"
├── div.kpi-card (항공편)
├── div.kpi-card (맛집/카페)
└── div.kpi-card#kpiBudgetCard (예상 경비)
    ├── ...기본 구조 동일
    ├── div#kpiExpenseActual  실제 사용 금액
    ├── div.expense-progress  프로그레스바
    └── div#kpiExpensePercent 예산 대비 %
```

| KPI 카드 | kpi-icon 색상 | kpi-value 예시 |
|----------|-------------|---------------|
| 여행 기간 | `var(--day1)` 블루 | 11박 12일 |
| 항공편 | `var(--day2)` 퍼플 | AY0042/0041 |
| 맛집/카페 | `var(--day3)` 그린 | 26 / 18곳 |
| 예상 경비 | `var(--day4)` 앰버 | ~₩6,200,000 |

- KPI 아이콘: 20x20 SVG, stroke-width 2, stroke 색상 = Day 색상
- 카드 애니메이션: `fadeInUp 0.6s`, delay 0.1s~0.4s 순차
- 모바일 카드: `display: flex; flex-direction: column; align-items: stretch`

  cost: Number|null, currency: 'EUR'|'KRW',
  mapUrl: String|undefined, mapLabel: String|undefined,
  nearby: String|undefined }

```js
{ name: String, subName: String|undefined, region: String,
  desc: String, reco: String, location: String,
  price: Number, badge: String, mapUrl: String|undefined,
  inSchedule: String|undefined }
```

### 9.3 SPOT_DATA

```js
{ name: String, subName: String, region: String,
  desc: String, location: String, admission: String,
  badge: String, mapUrl: String, inSchedule: String|undefined }
```

### 9.4 HOTEL_DATA

```js
{ name: String, subName: String, type: String,
  checkIn: String, checkOut: String, nights: Number,
  nightsDates: String[], address: String,
  pricePerNight: String, totalPrice: String,
  bookingUrl: String, mapUrl: String }
```

### 9.5 BUDGET_DATA

```js
{ category: String, emoji: String,
  items: [{ label: String, eur: Number, krw: Number }] }
```
