### 3. 목표 추적기 무한 로딩 버그 수정 (C등급 - 높은 우선순위)
**문제**: "📅 월간 성장 추적 중…" 메시지가 영구적으로 표시됨
**근본 원인**: NaN 또는 null 값이 isFinite() 검사 없이 처리됨
**해결책**:
- `monthlyGrowth` 계산에 `n()` 안전 래핑 추가
- `isFinite(monthlyGrowth)` 조건 검사 추가
- 오류 메시지를 "📅 데이터 부족"으로 변경

**검증**: ✅ 라인 1374

### 4. 누적 수익률 벤치마크 오버레이 수정 (D등급)
**문제**: 벤치마크 토글이 작동하지 않음
**해결책**:
- Card-title에 toggle 버튼 추가 (라인 578)
- `toggleBenchmark()` 함수 구현 (라인 1543)
- 상태 관리: `window.showBenchmark = false`로 초기화
- Chart.js 업데이트: 토글 상태에 따라 벤치마크 선 표시/숨김

**검증**: ✅ 라인 578, 1543

### 5. 목표 편집 모달 UI 개선 (E등급)
**변경**: `prompt()` → 폼 기반 모달
**구현**:
- `editGoal()` 함수: 첫 호출 시 모달 생성
- 실시간 목표 자산 미리보기: "예상 목표 자산: ₩5억"
- `submitGoalEdit()` 함수: 유효성 검사 및 저장
- 다크 테마 스타일 적용

**검증**: ✅ 라인 1386-1431

### 6. 목표 배분 JSON prompt() 모달 개선 (F등급)
**변경**: `prompt()` → 폼 기반 모달 UI
**구현**:
- `editTargetAlloc()` 함수: 완전히 새로 작성 (라인 1191-1279)
- 섹터별 입력 필드: 이름 | 입력 필드(%) | 비주얼 바 | 총 개수
- 실시간 계산: `updateAllocTotal()` 함수
- 색상 기반 검증:
  - 🟢 Green (#22c55e): 합계 = 100%
  - 🟣 Purple (#a855f7): 합계 < 100% 또는 > 100%
  - 🔴 Red (#ef4444): 합계 > 100%
- `submitTargetAlloc()` 함수: 합계 = 100% 검증 후 저장

**검증**: ✅ 라인 1191-1279, 1258
